# ObitoBotWA

Bot de WhatsApp baseado em Baileys.

## Instalação

1. Instale Node.js compatível com o projeto.
2. Execute `npm install`.
3. Inicie com `npm start`.

## Observações

- A integração externa de IA foi removida desta versão pública. O comando `!reflexao` usa reflexões locais e `!ia` informa que a integração está desativada.
- Dados de usuários, grupos, autenticação e logs são locais e ignorados pelo Git.
- Nunca publique credenciais, sessões do WhatsApp ou bancos de dados reais.
